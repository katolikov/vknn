The engine's class graph as an explorable map. Start from the one class an application touches and click any square to unfold the classes it owns or uses — one level at a time, the way you'd actually read the code. Click a square again to fold it back. The panel below the map explains the selected class in plain words. Prefer prose? The architecture reference covers the same ground linearly, and How VKNN works tells the story end to end.

Solid connectors mean "owns / creates"; dotted means "uses at run time". Every class appears once — when a second owner reaches it, a faded connector links back to the same square.
